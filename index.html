理論公式

Arrhenius equation

k = A exp(−Ea/RT)
Q10,A = exp{ (Ea/R) [1/T − 1/(T + 10)] }

假設前指數因子 A 在這段小溫度範圍內不變。

Simplified collision theory

k = C T1/2 exp(−Ea/RT)
Q10,C = [(T + 10)/T]1/2 Q10,A

T1/2 近似表示平均相對速率與 碰撞頻率的溫度效應。

10°C rule

Q10 = k(T + 10)/k(T) ≈ 2

Q10 = 2 代表溫度升高 10°C 後，速率常數約增加為原來的兩倍。

更進一步的物理與化學限制

  • 活化能依賴性： 活化能越大，速率常數通常對溫度越敏感， Q10 可能明顯大於 2。
  • 起始溫度依賴性： 即使活化能固定，相同的 10°C 升溫在不同 起始溫度下也不會產生相同倍率。
  • 反應機構改變： 如果升溫使主導步驟改變，表觀活化能與 速率方程式也可能改變。
  • 前指數因子不是絕對常數： 碰撞頻率、分子取向與熵效應都可能隨溫度 改變。
  • 非化學反應步驟控制： 擴散、傳質、表面吸附飽和或酵素變性， 都可能使簡單的 Arrhenius 模型失效。
